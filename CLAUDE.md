## Criterios Base FBA (siempre activos)

| Criterio | Valor mínimo |
|----------|-------------|
| BSR | ≤ 250,000 |
| ROI | ≥ 30% |
| Ganancia neta | ≥ $4.00 |
| Sellers FBA activos | ≥ 3 |

**Capital Etapa 1:** máx. $150 por producto — alerta si capital baja de $500

**Categorías prohibidas:** Electrónica, Ropa con talla, Vidrio/cerámica, Productos con variaciones (sin aprobación de Carlos)

**Fuente preferida:** Walmart / Target private label (aprobación automática)
